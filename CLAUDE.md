# Claude Code

OM0RX-xSuite is the public storefront and release catalog of the OM0RX suite (no app code). `suite.json` is the manifest; README.md and apps/*.md tables are generated by `python tools/xsuite.py render`. Read docs/RELEASING.md before staging or publishing: publish the GitHub release before pushing suite.json, never replace a published file, and check with `python tools/xsuite.py verify`.
